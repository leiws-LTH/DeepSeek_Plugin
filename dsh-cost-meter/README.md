# @local/dsh-cost-meter

在输入框右上方常驻一颗「速度 + 花费」胶囊，把当前会话的 token 消耗换算成钱；
点开还能看到本轮明细、实时单价和账户余额。

> 适配 DeepSeek Harness `0.2.2-rc.1`。安装方式见仓库根目录的 [README](../README.md)。

## 界面

折叠态（常驻，右对齐在输入框上沿）：

```text
⏱ 42.5 tok/s · ≈¥0.0620
```

点开后向上弹出面板：

- 本轮：未缓存输入、缓存读取、缓存写入、输出、命中率、速度、首字延迟、本轮花费
- 会话累计（带 `≈`，按当前时段单价估算）
- 实时单价：当前模型 + 高峰/空闲时段 + 命中 / 未命中 / 输出三档单价 + 下一次切换时间
- 剩余金额：充值余额与赠送余额（来自 DeepSeek 账户），带更新时间与失败重试

## 改价格 / 改节假日

全部在 `client.js` 顶部：

- `PRICES`：按模型、按时段（`idle` 空闲 / `peak` 高峰）的每百万 token 单价，单位元。
  默认收录 `deepseek-flash` 与 `deepseek-v4-pro`，来源是官方「模型 & 价格」页；调价后改这里。
- `HOLIDAYS`：中国法定节假日（`YYYY-MM-DD`，北京时间）。放进来的日期全天按空闲价；
  未填的日期按工作日处理，可能高估花费。每年放假安排公布后补一次即可。
- `BUILD_VERSION`：随 Harness 主版本同步，仅作为平台侧客户端元数据。

## 口径

- 计费输入 = 未缓存输入 + 缓存读取 + 缓存写入；缓存写入按未命中价计。
- 命中率 = 缓存读取 / 计费输入，四舍五入到 100 之前最多显示 99.9%。
- 速度 = 会话 `sessionStats.decodeTokens / decodeMs`；本轮速度只除本轮有计时的输出 token。
- 「本轮花费」按每个 step 完成时刻的时段单价累计，是精确值。
- 「会话累计」用整段会话的 token 汇总 × **当前**时段单价，带 `≈`，是估算；
  要精确到每次请求发生时刻，需要 Host 侧的逐 attempt 投影（目前未做）。
- 余额是平台侧数值，与本地累计花费不保证同步。

## 已知限制

- 会话跨高峰/空闲或中途切模型时，「会话累计」会偏；「本轮」不受影响。
- 法定节假日表默认为空，节假日按高峰计价（只高估，不低估）。
- 未登录 / 无账户权限时余额区块隐藏，胶囊只显示速度与本地花费。
- 宿主下方原有的 `activity` / `usage` 两颗统计胶囊保持原样，本插件不替换它们。

## 数据与隐私

- 不写任何文件，全部在浏览器内计算；余额通过本机 Host 的账户接口读取。
- 不上传用量、余额或对话内容。

## 卸载

在 设置 → 插件 中移除该 bundle，或在 Harness 中执行 `remove_bundle`。
本地目录安装是软链：**先移除再删目录**，否则 profile 会残留失效依赖。
