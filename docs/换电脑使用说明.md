# 两个插件：换电脑使用说明

这个文件夹里是两个本地插件，**都不在云端**，需要手动带到另一台电脑再安装一次。

- `dsh-cost-meter`：输入框右上方的「速度 + 花费」胶囊（价格写死在 `client.js` 的 `PRICES`）
- `dsh-usage-stats`：侧边栏「用量」面板 + 本机 token 账本
- `可选-用量历史/ledger.json`：这台电脑已有的用量账本（要不要带走见第 4 步）

---

## 1. 前提

- 另一台电脑安装**同一版本**的 DeepSeek Harness（本机是 `0.2.2-rc.1`）。
  插件用的是这个版本的 slot / 投影 / webserver 接口，跨大版本不保证兼容。
- 两个插件名是 `@local/...`，不来自 npm，必须从本地目录安装。

## 2. 拷贝

如果仓库已经推到 Git，新电脑直接 `git clone` 即可，跳过这一步的复制：

```bash
git clone https://github.com/leiws-LTH/DeepSeek_Plugin.git dsh-plugins
```

从 zip 走的话，把 `dsh-cost-meter` 和 `dsh-usage-stats` 两个文件夹放到新电脑一个
**不会被移动或删除**的位置，例如：

```text
D:\DeepSeek\插件\dsh-cost-meter
D:\DeepSeek\插件\dsh-usage-stats
```

> 本地目录安装是软链：安装后再删/移动文件夹，插件会失效（profile 里还记着这个路径）。

## 3. 安装

在新电脑上打开 DSH，新建一个会话，对 Agent 说：

> 安装这两个本地插件（从目录安装）：
> D:\DeepSeek\插件\dsh-cost-meter
> D:\DeepSeek\插件\dsh-usage-stats

Agent 会用插件管理器（`install_bundle`）分别安装；两个都应返回 `application: applied`。
装完侧边栏会出现「用量」，输入框右上方会出现花费胶囊。若没有，刷新一次页面。

## 4. 用量历史（可选）

想把这台电脑的历史用量带过去：

1. 先退出新电脑上的 DSH；
2. 把 `可选-用量历史/ledger.json` 复制到：
   `%USERPROFILE%\.dsh\storages\usage-stats\ledger.json`
   （若目录不存在就新建；如果新电脑已经有账本，先备份再覆盖）
3. 重新打开 DSH，面板里就是两边合并后的历史。

不带也可以：插件会自动回填新电脑上已有的会话记录，只是没有这台电脑的数据。

## 5. 验证

- 设置 → 插件：能看到 `@local/dsh-cost-meter`、`@local/dsh-usage-stats`；
- 侧边栏点「用量」：有今日 / 近 7 天 / 近 30 天 / 累计，图表和模型表；
- 随便发一条消息：胶囊的数字会动，面板「今日」会涨。

## 6. 以后怎么同步

现在没有云端同步，最省事的三条路：

1. **网盘目录**：把 `D:\DeepSeek\插件` 放进 OneDrive / 坚果云，两台电脑都装在这个同步目录里——文件夹路径一致时，profile 里的软链两边都能用（新电脑仍要各自装一次）。
2. **私有 Git 仓库**：把两个插件目录提交到一个私有仓库；新电脑 clone 后按第 3 步从 clone 出来的目录安装。改价、改配置都能版本化。
3. **发到 npm（私有或公开）**：把两个包发布成 `@your-scope/dsh-cost-meter` 这类名字，之后在新电脑用插件管理器按包名安装，最接近“云同步”。

## 7. 注意

- `dsh-cost-meter` 的价格表：`client.js` 顶部的 `PRICES`（`deepseek-flash` / `deepseek-v4-pro`，空闲/高峰两档）。
- `dsh-usage-stats` 的配置：`cordis.patch.yml` 里的 `timeZone`（默认 `Asia/Shanghai`）与 `backfill`。
- 用量面板只统计**经过该电脑 Harness** 的调用；两台电脑的账本可以合并，但不会实时互相同步。
- 账本损坏或想重算：面板右下角「重建统计」，或删掉 `ledger.json` 后重启。
